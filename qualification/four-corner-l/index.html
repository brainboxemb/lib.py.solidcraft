Four centred vertical L-profiles

1. Test setup

Test goal

Place one short vertical angle profile around each of the four rounded side corners of a rectangular frame. The profile is centred in height and wraps the two adjacent side faces instead of lying flat on a front/rear face.

Pass criteria

One vertical angle profile wraps each front-left, front-right, rear-right and rear-left rounded side corner. All four occupy Z=22..38 on the 60 mm frame.

Mutation criterion

Change frame_width/depth from 120x80 to 160x120 mm in the saved .sc design; all four profiles follow the moved side corners while remaining centred at the same frame height.

2. Implementation under test

Fixture source

"""Four vertical L-profiles centred on the four rounded side corners."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    _height = 60.0

    def build(self):
        return Box(
            self._width,
            self._depth,
            self._height,
        ).fillet(8, edges=Edges.VERTICAL)


class LProfile:
    ARM_LENGTH = 28.0
    THICKNESS = 4.0
    PROFILE_HEIGHT = 16.0

    def build(self):
        # A real angle profile around a vertical corner. Local +X/+Y is the
        # inside of the case; material sits just outside those two faces.
        with Sketch(name="Profile", plane="XY") as sketch:
            Polygon2D(
                [
                    (0, 0),
                    (self.ARM_LENGTH, 0),
                    (self.ARM_LENGTH, -self.THICKNESS),
                    (-self.THICKNESS, -self.THICKNESS),
                    (-self.THICKNESS, self.ARM_LENGTH),
                    (0, self.ARM_LENGTH),
                ],
                plane="XY",
            )
        return sketch.extrude(
            self.PROFILE_HEIGHT,
            direction=Direction.POSITIVE,
        )


class FourCornerL:
    frame_width = 120.0
    frame_depth = 80.0
    frame_height = 60.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        profile = LProfile()

        frame_xy = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.RIGHT,
        )
        profile_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.DOWN,
            x=Anchor.RIGHT,
        )

        half_width = half(self.frame_width)
        half_depth = half(self.frame_depth)
        centre_height = half(
            self.frame_height - LProfile.PROFILE_HEIGHT
        )

        front_left = profile.copy().attach(
            frame,
            parent=frame_xy,
            child=profile_origin,
            offset=(-half_width, -half_depth),
            gap=centre_height,
            angle=0,
        )
        front_right = profile.copy().attach(
            frame,
            parent=frame_xy,
            child=profile_origin,
            offset=(half_width, -half_depth),
            gap=centre_height,
            angle=90,
        )
        rear_right = profile.copy().attach(
            frame,
            parent=frame_xy,
            child=profile_origin,
            offset=(half_width, half_depth),
            gap=centre_height,
            angle=180,
        )
        rear_left = profile.copy().attach(
            frame,
            parent=frame_xy,
            child=profile_origin,
            offset=(-half_width, half_depth),
            gap=centre_height,
            angle=270,
        )

        return frame + front_left + front_right + rear_right + rear_left


FourCornerL()

Public Forge API used

LProfile + one assembly-local XY AnchorFrame; planar X/Y offsets select the four side corners, gap selects height, and angle=0/90/180/270 clocks the same neutral profile.

Forge model represented by this fixture

One rounded parametric FrameBlock plus four occurrences of one vertical LProfile definition. The child is a true XY angle section extruded in Z; the assembly owns only corner position, height and clocking.

3. Generated SolidCraft relationship

Four planar joint.create commands share one parent XY frame at Z=0. Symbolic X/Y offsets use frame_width/frame_depth and a symbolic normal offset centres the fixed-height profile vertically. Placement does not depend on a sharp corner edge, so the frame may keep its vertical fillets.
