SCPF Forge verification

Qualification

Every non-trivial Forge feature is traced from Python API through compiler representation and native SolidCraft behaviour. A green unit test alone is not treated as proof that the CAD result is correct.

Source commit: 794210b663fe50b1fcc899b4a01a46f1eac657d0 · SolidCraft 0.30.1

Status: PASS means every required qualification level passed; FAIL means a semantic or visual check found an actual mismatch; REVIEW means machine checks may be valid but the fixed-camera visual result still needs an explicitly approved reference; INCOMPLETE means required evidence is missing.
